# ЛИНЕЙКА

Адаптивный одностраничный сайт по ТЗ `LINEYKA_SITE_EXACT_REFERENCE_PROMPT.md` и приложенному PNG-референсу. Реализованы все шесть разделов, четыре преимущества, FAQ, мобильное меню и форма. Текст — HTML, фирменная линия — настоящий SVG path, пересчитываемый по геометрии DOM.

## Запуск

Требуется Node.js 18 или новее. Внешних зависимостей для сайта нет.

```sh
cd lineyka
node server.mjs
```

Открыть http://127.0.0.1:4173. На этом Mac можно дважды нажать `Открыть сайт.command`: он использует установленный Node.js либо встроенный runtime Codex.

```sh
node build.mjs          # готовая статическая версия → dist/
node server.mjs --dist  # проверить собранную версию
```

`dist/` можно разместить на любом статическом хостинге. Все картинки и шрифты локальные; CDN, аналитики и внешних запросов при открытии страницы нет. `.openai/hosting.json` содержит идентификатор приватного сайта Sites.

## Структура и редактирование

- `index.html` — содержание, навигация, подписи и поля формы.
- `style.css` — бумажный фон, сетка, шрифты и адаптивные композиции.
- `app.js` — FAQ, меню, валидация, отправка и построение красного маршрута.
- `content.js` — редактируемые ответы FAQ и настройки подключения формы.
- `public/images/` — девять отдельных фотографий WebP, созданных инструментом image_gen. Это реконструкции, а не оригинальные фотографии компании.
- `ASSET_PROMPTS.json` — точные промпты каждого изображения и название использованного инструмента.
- `public/fonts/` — кириллические Bebas Neue Bold, Oswald, Inter; Roboto Condensed оставлен для сравнения. Файлы лицензий входят в комплект.
- `screenshots/` — полностраничные снимки 941, 1440, 390 и 320 px и JSON-отчёт проверки.
- `scripts/verify.mjs` — воспроизводимая браузерная проверка.

При замене фотографий сохраняйте имена файлов либо обновляйте `src` в HTML. Меняйте также `alt`, если меняется содержание фотографии. Широкие преимущества располагаются в четыре колонки, на 768–1199 px — 2×2, на телефоне — последовательно. Услуги на телефоне превращаются в вертикальный каталог, этапы — в вертикальную шкалу.

## Форма

Сейчас включён **деморежим**. Имя и телефон проверяются только в браузере. Данные не передаются, не записываются в localStorage/sessionStorage и не логируются. Результат прямо сообщает, что заявка не отправлена. Контакты компании не выдуманы.

Для подключения реального обработчика в `content.js` нужно указать:

```js
demoMode: false,
formEndpoint: 'https://ваш-домен/обработчик',
privacyUrl: 'https://ваш-домен/политика-конфиденциальности',
```

Реальный режим включается, только если присутствуют оба HTTPS-адреса. Тогда показывается обязательное, изначально неотмеченное согласие со ссылкой на действительную политику. При неполной конфигурации форма остаётся демонстрационной. Сначала подготовьте и утвердите политику, условия обработки и текст согласия для конкретного оператора; образец юридического документа не выдаётся за действующую политику.

Обработчик получает `POST` с `Content-Type: application/json`:

```json
{"name":"…","phone":"…","service":"Склады","consent":true}
```

Он должен самостоятельно проверять поля и согласие, сохранять заявку или передавать её в CRM и возвращать успешный HTTP-код **только после фактического принятия заявки**. Для другого домена требуется CORS. Тайм-аут — 15 секунд. Ошибки сети и HTTP отображаются в форме. Интеграция с CRM/Telegram/email в эту версию не подключена: реквизиты не предоставлены.

Ответы FAQ пока являются нейтральными редактируемыми черновиками и раскрываются с соответствующей пометкой. Перед публичным запуском необходимо утвердить их, географию работы из Hero и формулировки услуг у владельца. Не отключайте деморежим, чтобы скрыть черновые пометки без проверки содержания.

## Проверка

Сайт проверен в Chromium при 320, 375, 390, 768, 941, 1024 и 1440 px. Проверяются отсутствие горизонтальной прокрутки, загрузка всех ассетов и SVG, мобильное меню, Escape, клавиатурный FAQ, ошибки формы, состояние загрузки, честный результат деморежима, отсутствие передачи и сохранения введённых данных, `prefers-reduced-motion`. Отдельно проверяются успешный и неуспешный ответы тестового обработчика без реальной передачи персональных данных.

Для повторения при работающем локальном сервере:

```sh
npm install --no-save playwright
npx playwright install chromium
node scripts/verify.mjs
```

Если Playwright уже имеется в другой папке, его ESM entry point можно передать через `LINEYKA_PLAYWRIGHT_PATH`.

## Отличия от исходного изображения

Это кодовая реконструкция, не подтверждённая копия пиксель-в-пиксель:

1. Оригинальные фотографии отсутствовали. Девять сцен созданы отдельно; ракурсы, работники и детали оборудования отличаются.
2. Исходный шрифт не предоставлен. Для больших капительных заголовков после сравнения выбран Bebas Neue с кириллицей, для остальных — Oswald и Inter. Начертания, метрики и логотип могут отличаться.
3. Внесён предусмотренный ТЗ четвёртый пункт о персональном менеджере. На средних ширинах сетка 2×2 увеличивает высоту раздела относительно исходных трёх колонок.
4. Маршрут красной линии адаптируется к DOM; часть соединений проходит за краями листа. Изгибы близки по характеру, но не идентичны исходному изображению. Анимация прорисовки не добавлена: линия статична и не мешает чтению.
5. В форме вместо неподтверждённой отправки и фиктивного юридического документа показан явный деморежим.

Источники шрифтов: [Bebas Neue / Dharma Type и Fontfabric](https://github.com/dharmatype/Bebas-Neue), [Google Fonts](https://github.com/google/fonts). Все лицензии сохранены в `public/fonts/`.
