# ЛИНЕЙКА

Адаптивный одностраничный сайт по ТЗ `LINEYKA_SITE_EXACT_REFERENCE_PROMPT.md` и приложенному PNG-референсу. Нумерация блоков и пунктов убрана. Кнопки «Склады», «Производство» и «Логистика» открывают окна с описаниями услуг. Адрес, телефон и электронная почта находятся в подвале сайта. Текст — HTML, фирменная линия — настоящие SVG path, пересчитываемый по геометрии DOM.

## Запуск

Требуется Node.js 18 или новее. Внешних зависимостей для сайта нет.

```sh
cd lineyka
node server.mjs
```

Открыть http://127.0.0.1:4173. На этом Mac можно дважды нажать `Открыть сайт.command`: он использует установленный Node.js либо встроенный runtime Codex.

```sh
node build.mjs          # готовая статическая версия → dist/
node server.mjs --dist  # проверить собранную версию
```

`dist/` можно разместить на любом статическом хостинге. Все картинки и шрифты локальные; CDN, аналитики и внешних запросов при открытии страницы нет. `.openai/hosting.json` содержит идентификатор приватного сайта Sites.

## GitHub и Vercel

Основной репозиторий: https://github.com/abdulguna216-pixel/lineika.

Для импорта на Vercel выберите этот репозиторий и корневую папку проекта. Файл `vercel.json` задаёт сборку `node build.mjs` и каталог публикации `dist`. Секреты и переменные окружения для текущей статической версии не нужны. После подключения Git-интеграции изменения ветки `main` публикуются автоматически.

## Структура и редактирование

- `index.html` — содержание, навигация и контакты в подвале.
- `style.css` — бумажный фон, сетка, шрифты и адаптивные композиции.
- `app.js` — FAQ, меню, окна услуг и построение красного маршрута.
- `content.js` — описания услуг и ответы FAQ.
- `public/images/` — отдельные фотографические сцены, восстановленные инструментом image_gen по утверждённому референсу. В текущей версии используются файлы `*-ref.webp`, `hero-matched.webp` и прозрачный слой `coordinator-cutout.webp`. Предыдущие варианты сохранены, но на странице не используются.
- `REFERENCE_ASSETS.json` — промпты восстановления сцен из референса. `ASSET_PROMPTS.json` относится к предыдущим неиспользуемым вариантам.
- `public/brand.svg` — векторная реконструкция логотипа из предоставленного референса.
- `public/fonts/` — кириллические Bebas Neue Bold, Oswald, Inter; Roboto Condensed оставлен для сравнения. Файлы лицензий входят в комплект.
- `screenshots/` — полностраничные снимки 941, 1440, 390 и 320 px, сравнение с референсом рядом (`reference-comparison.png`), геометрия секций (`reference-geometry.json`) и JSON-отчёт проверки.
- `scripts/verify.mjs` — воспроизводимая браузерная проверка.

При замене фотографий сохраняйте имена файлов либо обновляйте `src` в HTML. Меняйте также `alt`, если меняется содержание фотографии. На десктопе и планшете преимущества располагаются в три колонки как на референсе, на телефоне — последовательно. Дополнительный пункт о менеджере убран по последнему указанию повторить изображение без дополнений. Услуги на телефоне превращаются в вертикальный каталог, этапы — в вертикальную шкалу.

## Проверка

Сайт проверен в Chromium при 320, 375, 390, 768, 941, 1024 и 1440 px. Проверяются отсутствие горизонтальной прокрутки, загрузка всех ассетов и SVG, мобильное меню, Escape, клавиатурный FAQ, открытие трёх окон услуг, закрытие мышью и клавиатурой, возврат фокуса и ссылки на контакты.

Для повторения при работающем локальном сервере:

```sh
npm install --no-save playwright
npx playwright install chromium
node scripts/verify.mjs
```

Если Playwright уже имеется в другой папке, его ESM entry point можно передать через `LINEYKA_PLAYWRIGHT_PATH`.

## Совпадение с референсом и ограничения

По последнему указанию владельца все основные разделы на десктопе получили одинаковую высоту с Hero: 452 px при ширине 941 px и около 692 px при ширине 1440 px. Общая высота задаётся переменной `--desktop-panel-height`. Заголовки, фотографии и интервалы увеличены под новый размер секций; SVG следует геометрии обновлённых блоков. FAQ при раскрытии ответов может увеличиваться по содержимому. На телефоне высота остаётся свободной. В преимуществах три пункта, нумерации нет. Файлы `reference-comparison.png` и `reference-geometry.json` описывают предыдущий этап воспроизведения исходного изображения; текущие снимки — `desktop-941.png`, `desktop-1440.png` и мобильные версии.

Это полноценная HTML-вёрстка: текст, кнопки и ссылки доступны с клавиатуры, а красная линия строится SVG по геометрии блоков. Исходный скриншот не используется фоном страницы или её секций. Для логотипа отдельно восстановлен векторный знак.

Оригинальные фото и исходная гарнитура не предоставлены. Фотографические сцены восстановлены отдельно с передачей конкретного ракурса референса, поэтому детали коробок, оборудования и людей отличаются. Гарнитуры — Bebas Neue, Oswald и Inter; ширина строк заголовков подогнана к референсу. Фото и очертания букв не заявляются идентичными пиксель-в-пиксель.

Источники шрифтов: [Bebas Neue / Dharma Type и Fontfabric](https://github.com/dharmatype/Bebas-Neue), [Google Fonts](https://github.com/google/fonts). Все лицензии сохранены в `public/fonts/`.

## Автоматическое обновление на основном домене

Сайт: https://lineikasite.ru/

Измените исходные `index.html`, `style.css`, `app.js`, `content.js` или файлы в `public/`, затем отправьте commit в ветку `main` либо влейте pull request. Сайт автоматически собирается и обновляется примерно через 1–2 минуты. Публиковать сгенерированную папку `dist/` не нужно.

Перед публикацией проверяются синтаксис JavaScript и наличие локальных ресурсов HTML/CSS. При технической ошибке остаётся предыдущая рабочая версия. Проверки не оценивают правильность текста и дизайна.
